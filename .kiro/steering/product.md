# Product and implementation guidance

Codex-authored starting guidance, not Kiro-use evidence. Ghostlight teaches incident response through safe simulations. Preserve browser-only operation, no secrets and no production access. Prefer small dependency-free ES modules. Keep scores bounded and recovery deterministic. Use accessible controls, textContent, responsive layouts and reduced motion. Run npm test after changing the engine. Clearly distinguish simulated telemetry from real data. Never invent tool usage, team credentials, or hackathon eligibility.
